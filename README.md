# 中药执业药师备考资料站

一个纯静态的备考资料集合网站，包含考试介绍、四门科目知识框架、高频考点、记忆口诀、备考计划、课件视频导航、在线模拟试卷和逐章精讲讲义，可离线使用，方便分享给朋友一起备考。

> **2026 年考试新规：** 各科目每科 100 题、满分 100 分、考试时长 90 分钟、60 分合格，实行机考（2025 年起调整）。题型分布：A 型 40 + B 型 45 + C 型 10 + X 型 5，每题 1 分；X 型题全对才得分。本站模拟卷已按新题型配比编制。

## 使用方法

### 方式一：直接打开（零安装）

1. 把整个文件夹发给朋友（或解压 zip）。
2. 双击 `index.html`，用浏览器打开即可。
3. 所有页面离线可用，无需联网。

### 方式二：上传到免费静态托管（生成链接分享）

推荐 Gitee Pages（国内访问快）或 GitHub Pages：

- **GitHub Pages**：把文件夹内容推到 GitHub 仓库，在仓库 Settings -> Pages 中选择分支即可，访问地址形如 `https://用户名.github.io/仓库名/`。
- **Gitee Pages**：把文件夹推送到 Gitee 仓库，在「服务 -> Gitee Pages」开启部署。
- 也可以直接用 Cloudflare Pages、Vercel、Netlify 等，拖拽文件夹即可部署。

## 小功能

- 每页顶部搜索框可即时过滤本页内容。
- 各页「学习打卡」勾选状态保存在本机浏览器（localStorage），换设备不保留。
- 「模拟试卷」支持在线作答、自动判分、查看解析，可反复练习。
- 模拟卷按正式考试题型配比编制（A/B/C/X 四种题型，每题 1 分），B 型配伍题展开为逐题配作答。
- 打印页面时导航和搜索框自动隐藏，方便把资料页打印出来背。

## 内容说明

- 站内资料为原创整理，供备考学习交流使用，不构成报考依据或用药建议。
- 报考条件、报名时间、合格线、法条数字等政策每年可能调整，请以「中国人事考试网（cpta.com.cn）」和当年官方教材为准。
- 视频页链接已逐条核验可观看（核验日期见视频页），B 站资源可能被平台随时下架，失效时可用页内备用搜索找同类课程。
